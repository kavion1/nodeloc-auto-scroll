# NodeLoc Auto Scroll & Evidence-Grounded Replier

NodeLoc 自动漫游、成长指标看板与有依据的人工确认回帖 Tampermonkey 用户脚本。

## 🌟 核心功能

- **🚀 智能拟真漫游**：
  - 支持分段拟真阅读停顿（模拟人类注意力）与匀速慢划模式。
  - **Discourse 深度适配**：对齐 Discourse 约 60 秒上报一次 timing 的阅读时长累积机制。
  - **6 分钟收益封顶强切**：单帖达到 360 秒时长天花板后自动平滑切帖，长帖无须死等滚到底部。
  - **分屏/独立窗口友好**：仅在同窗口切走标签页或系统最小化时智能挂起，独立抽出窗口挂机不中断。
  - **SPA 平滑路由**：利用 Discourse Native 路由无刷新跳转下一篇，体验流畅。
- **📈 成长指标看板**：
  - 一键读取 NodeLoc 官方“升级进度”面板，包含阅读时长、回复数、进入话题数、阅读贴数、访问天数、获赞/给赞等 7 项指标。
  - **静默读取**：自动采集数据并静默关闭官方下拉菜单，绝不遮挡当前阅读视野。
  - **达标差额直观统计**：自动计算“还差 X 篇 / 还差 X 分钟”，奇偶卡片自适应排版。
- **🤖 智能回帖与抽奖口令识别**：
  - 自动识别“抽奖 / 口令 / 福利”帖，严格匹配口令格式，避免无效回复。
  - 解决长帖楼层截断问题（合并 DOM 加载楼层与后台 API 楼层），事实提取更精准。
  - 严格杜绝 AI 套话（如“感谢分享/干货满满”），生成口语化、友善中肯的跟帖候选。
  - 实时字数提示与微调发送延迟。
- **⚙️ 现代卡片 UI 与快捷交互**：
  - 双轨实时进度条：同时展现“页面滚动深度”与“驻留时长 / 目标时长”。
  - 超轻量迷你胶囊态：收起后仅占极小区域，胶囊上自带呼吸灯与「⏸/▶」快捷启停按钮。
  - 支持 NewAPI JSON 一键导入、支持复制完整无截断的请求与模型返回日志。
  - 完美适配亮色/暗色主题，自由拖拽。

## 📥 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展。
2. 安装脚本：
   - 点击打开本仓库中的 [`nodeloc_auto_scroll.user.js`](./nodeloc_auto_scroll.user.js) 并点击“Raw / 安装”。
   - 或在 Tampermonkey 中新建脚本，将 `nodeloc_auto_scroll.user.js` 的完整代码复制粘贴后保存。
3. 打开 [NodeLoc 论坛](https://www.nodeloc.com/)，进入任意帖子页面即可看到悬浮控制面板。

## 🎮 快捷键与操作

- `P`：暂停或恢复自动漫游
- `S`：跳过当前帖子并进入下一篇
- **面板控制**：
  - 顶部双轨：实时查看滚动比例与驻留秒数
  - 快捷按钮：随时暂停、跳过或调整单帖目标驻留时长（默认 120s）
  - 右上角「一」：折叠为轻量悬浮胶囊

## ⚙️ AI 配置说明

1. 切换至「⚙️ 设置」标签页。
2. 支持直接将 NewAPI 格式 JSON 粘贴至导入框自动填入，或手动输入：
   - **Base URL**：如 `https://api.openai.com` 或镜像站地址（需带 `https://`）
   - **API Key**：你的 API 密钥
   - **模型名称**：如 `gpt-4o-mini`、`claude-3-5-haiku-20241022` 等
3. 所有密钥与配置均仅通过 Tampermonkey 的 `GM_setValue` 保存在本地浏览器，不会上传至任何第三方服务器。

## 🔐 脚本权限

- `GM_setValue` / `GM_getValue`：本地持久化保存配置、阅读记录与历史
- `GM_setClipboard`：一键复制完整请求日志与候选回复
- `GM_xmlhttpRequest`：跨域调用用户配置的 LLM 接口
- `@connect *`：连接用户自定义的模型 API 域名
