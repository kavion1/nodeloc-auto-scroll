# NodeLoc Auto Scroll & Evidence-Grounded Replier

> **当前版本**：v21.6.0（胶囊全能交互版 · 深度融合 shuorenhua 去 AI 味引擎）

NodeLoc 自动拟真漫游、成长指标看板与有依据的人工确认回帖 Tampermonkey 用户脚本。

---

## 🌟 核心功能亮点

### 1. 💊 全能迷你悬浮胶囊（折叠即全控）
- **胶囊全屏自由拖拽**：主面板和折叠后的胶囊均支持按住任意拖动，松手即停靠。
- **内置微位移防误触算法**：仅在位移大于阈值时判定为拖拽，点击空白处平滑展开，绝不误触。
- **右下角基准平滑缩放**：收缩与展开均以右下角为基准计算锚点，杜绝面板展开时突然跳屏或移出视野。
- **胶囊三合一快捷微控**：
  - `⏸ / ▶`：无需展开面板，胶囊上直接一键暂停或继续漫游；
  - `⏭`：直接跳过当前帖子，平滑加载并阅读下一篇；
  - `📈 TL`：点击直达“成长指标看板”，一键查看等级达标情况。

### 2. 🌿 深度融合 `shuorenhua`（说人话）去 AI 味引擎
- **5 大论坛高频场景自适应感知**：
  - 🎁 **抽奖福利**：精准识别楼主与各楼层抽奖口令格式，口令帖优先输出严谨口令，无口令帖随手真诚祝愿参与；
  - ⚡ **测速技术**：围绕晚高峰、回程路由、延迟、丢包或套餐性价比客观交流，保持技术真实感；
  - 💰 **集市交易**：聚焦机器配置、剩余价值、续费成本、push 费用，简明扼要；
  - 🛠️ **排障求助**：直击关键排查方向（端口、防火墙、DNS 等），拒绝无效安慰；
  - 💬 **日常杂谈**：随和接地气，就像手机真人在论坛敲字，末尾严禁加句号。
- **彻底根除四大 AI 反模式与套话**：
  - 禁模板套话（“感谢分享/干货满满/受益匪浅/字字珠玑”）；
  - 禁二元假对比（“与其说……不如说……”、“不是……而是……”）；
  - 禁假升华与宏大愿景（“让我们拭目以待”、“开启新篇章”、“迈向新台阶”、“里程碑”）；
  - 禁机械过渡与客服反问（“总的来说”、“综上所述”、“希望对你有帮助”、“你怎么看呢”）。

### 3. 🚀 智能拟真漫游与 Discourse 机制深度对齐
- **Discourse Timing 机制对齐**：对齐 Discourse 约 60 秒上报一次阅读时长的规则，有效积累阅读天数与时长。
- **6 分钟收益封顶强切**：单帖达到 360 秒时长天花板后自动平滑切帖，长帖无须死等滚到底部。
- **分屏/独立窗口挂机友好**：基于 Page Visibility API，独立抽出窗口或多任务分屏时绝不误暂停。
- **Discourse SPA 平滑路由**：利用论坛内部路由原生跳转，无需整页刷新。

### 4. 📈 成长指标看板（官方数据静默采集）
- 一键读取 NodeLoc 官方“升级进度”面板（阅读时长、回复数、进入话题、阅读贴数、访问天数、获赞/给赞 7 项数据）。
- **静默读取与清理**：数据抓取完成后自动静默关闭官方下拉菜单，不遮挡阅读视野。
- **直观差额统计**：清晰标注“已达标”或“还差 X 篇 / 还差 X 分钟”，末尾奇数卡片自适应跨行铺满。

## 📥 安装使用

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 安装脚本：
   - 打开本仓库中的 [`nodeloc_auto_scroll.user.js`](./nodeloc_auto_scroll.user.js) 点击安装；
   - 或在 Tampermonkey 新建脚本，复制完整代码保存。
3. 打开 [NodeLoc 论坛](https://www.nodeloc.com/)，进入任意帖子页面即可体验。

---

## 🎮 快捷键与操作

- `P`：暂停或恢复自动漫游
- `S`：跳过当前帖子并进入下一篇
- **面板控制**：
  - 双轨进度条：直观展示页面滚动深度与驻留计时（及 360s 封顶状态）；
  - 右上角「一」：折叠为轻量可拖拽胶囊；
  - 胶囊态：随时通过内嵌按钮启停、跳篇或展开成长指标。

## ⚙️ AI 配置说明

1. 切换至「⚙️ 设置」标签页。
2. 支持直接将 NewAPI JSON 导入，或手动填入：
   - **Base URL**：如 `https://api.openai.com` 或第三方中转地址（需包含 `https://`）
   - **API Key**：你的 API 密钥
   - **模型名称**：推荐使用极速高性价比模型（如 `claude-haiku-4-5`、`gpt-4o-mini`）
3. 所有配置仅通过 Tampermonkey 的 `GM_setValue` 本地保存，绝不上传到任何第三方服务器。
